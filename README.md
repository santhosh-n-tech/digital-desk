## About

The Digital Desk — StudyFlow is a clean, pastel-themed productivity dashboard designed to help students and professionals organize daily tasks, focus on important work, and track their progress.

## Features

* **Focus Timer** — A 25-minute timer for focused work sessions.
* **Task Management** — Add, complete, and delete tasks.
* **Progress Tracking** — Monitor task completion.
* **Daily Dashboard** — Keep daily planning organized.
* **Pastel UI** — A clean and minimal interface.

## Getting Started

**Run locally**

```bash
git clone https://github.com/santhosh-n-tech/digital-desk.git
```

Open the project folder and launch `index.html` in your browser.
